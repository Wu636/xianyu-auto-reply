# X 长文采集扩展

1. Chrome 打开 `chrome://extensions/` 并开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录。
3. 在本地系统“链接商品化”页面生成扩展配对码，粘贴到扩展。
4. 打开 X 帖子，展开长文并滚动到希望采集的线程末尾，再点扩展图标采集。

更新扩展代码后，请在 `chrome://extensions/` 找到本扩展并点击“重新加载”；版本号应显示为 `1.0.1`。采集状态会分别显示发现的图片数、成功保存数和下载失败数。

扩展只发送页面已经展示的长文、同作者线程、帖子链接、作者名和最多八张图片。它复用当前 Chrome 已登录页面的可见内容，X Cookie 始终留在浏览器内。
