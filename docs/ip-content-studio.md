# 个人 IP 内容工厂

“个人 IP 内容工厂”与原来的“X 长文商品化”彼此独立：前者把参考资料重构成你自己的多平台内容，后者继续负责将原始材料整理为可交付商品。

## 处理流程

1. 进入后台侧栏的 **IP 内容工厂**。
2. 创建 IP 档案，填写名称、定位、受众、语气、真实经历、固定开场/结尾、禁用表达和视觉风格。
3. 选择来源：
   - 从“链接商品化”已采集的本机 Chrome 内容中载入；
   - 填写链接并粘贴正文；
   - 直接输入选题或素材。
4. 点击 **分析来源**。系统会将知识、方法、证据与原作者身份、自我介绍、推广内容、课程广告、平台指标拆开显示。
5. 选择创作角度、输出平台和来源配图策略，再点击 **生成个人 IP 内容**。
6. 在编辑区修改主稿和平台版本，确认事实、原创性及来源身份清理结果。
7. 查看原创 IP 配图与来源图审核结果。来源图可逐张选择“保留并标注来源”“改用原创 IP 图”或“不使用”，同时指定插入章节、图片说明和裁剪/遮挡提醒。
8. 点击 **保存来源图审核并重新导出**，系统会重新生成 Markdown、公众号 HTML、DOCX、PDF 与完整 ZIP。
9. 下载 ZIP、Markdown、公众号 HTML、DOCX 或 PDF。

## 智能混合配图

生成前可选以下策略：

- **智能混合（推荐）**：界面、步骤、参数、数据和前后对比图优先进入人工审核；概念图优先由统一视觉 IP 重绘；头像、课程宣传、二维码、联系方式及敏感信息默认排除。
- **全部使用原创 IP 图**：来源图片不进入成稿，只使用统一视觉指纹生成的新图。
- **只保留必要原图**：仅让关键信息型截图进入审核，数量更克制。
- **尽量保留全部原图**：所有来源图进入人工审核，适合你拥有图片使用权且希望保留原始图文结构的场景。

系统会分析每张来源图的信息价值、建议处理方式和适合插入的章节。AI 判断只是初筛，发布前以编辑区的逐图选择为准。被保留的来源图会复制进项目资产目录，正文下方自动显示图片说明、来源作者和原文链接；审核记录同时写入 `source-image-review.json` 与项目清单。

## 视觉 IP 素材库

每个 IP 档案都有一套独立视觉库，数据分成两层：

- **视觉指纹**：固定人物名称与外观、标志性元素、统一风格关键词、品牌色、封面规则、正文配图规则、固定提示词模板和排除项。
- **素材资产**：人物定妆、动作、表情、服装、固定场景、风格参考、封面模板和历史成图。

推荐首次按下面顺序建立素材库：

1. 先填写人物外观、标志性元素、统一画风及封面/正文规则，点击“保存视觉指纹”。
2. 上传 3—8 张清晰参考图，并为每张图填写类型、标签和必须保持的细节。
3. 从最能代表人物外观和画风的素材中选择一张“主参考”。
4. 使用“按视觉指纹生成新素材”制作第一批封面和正文场景图。
5. 在创作项目的配图库中，把满意的成图“收藏到视觉素材库”。收藏图会复制到独立目录，删除项目后仍会保留。

项目批量生图和单张重生成都会注入同一份视觉指纹，并优先把“主参考”、收藏素材及近期素材作为参考图发送给兼容的图片编辑接口。若当前生图供应商只开放文生图接口，系统会自动沿用素材名称、标签、连续性说明和视觉指纹生成，并把降级提示保存在项目质量提醒中。

## 输出内容

- **公众号**：完整长文、标题层级、引用、列表、段落配图和自包含 HTML。
- **小红书**：标题、正文、标签和卡片文案。
- **抖音**：3 秒开头、口播稿、分镜、字幕和封面字。
- **X**：适合连续发布的 Thread。
- **通用文件**：Markdown、DOCX、PDF、质量报告、来源分析和 IP 档案快照。

## 内容隔离原则

- 生成提示只读取清洗后的知识、观点、方法、证据、案例和事实提醒。
- 原作者姓名、自我介绍、个人经历、课程推广、联系方式和互动指标进入排除区，不进入写作素材。
- 涉及个人经历的表达只从当前 IP 档案的“真实经历”中选取。
- 生成后再次执行相似度与来源身份污染检查；检查结果会随项目保存并进入导出包。
- 默认采用智能混合配图：信息型来源图经逐张审核后可引用并标注出处，其余内容按当前 IP 档案的视觉风格、品牌色与文章主题生成原创配图。
- 来源图的头像、推广、二维码、联系方式、密钥、余额和隐私信息默认排除；需要保留时先在审核区填写裁剪/遮挡提醒并人工复核。

## 档案填写建议

- **定位**：一句话说明“你帮助哪类人解决什么问题”。
- **受众**：尽量具体，例如“想用 AI 提升内容效率的个体创作者”。
- **真实经历**：每条写清背景、动作和结果；没有数据时不虚构数字。
- **开场模板**：例如“大家好，我是{name}。最近我在实践{topic}时发现……”
- **禁用表达**：填写你不想出现的口头禅、夸张承诺和敏感词。
- **视觉风格**：写明人物形象、服装、构图、质感、品牌色及要避开的元素。
