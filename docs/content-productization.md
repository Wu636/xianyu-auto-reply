# X 长文商品化

这条本地流水线把 X 长文、同作者线程和图片采集到管理后台，再生成可编辑的闲鱼标题、商品介绍、AI 封面和交付文件。交付形式可同时勾选 Markdown、PDF、飞书文档、Skill；生成后仍可在商品发布表单中修改标题、详情、价格、类目和多张图片。

## 1. 安装 Chrome 采集扩展

1. 启动项目并访问 `http://127.0.0.1:8090/`，进入“链接商品化”。
2. 点击“生成扩展配对码”。配对码只用于把扩展采集的数据写入当前用户，本地加密保存；X Cookie 始终留在 Chrome 内。
3. 在 Chrome 打开 `chrome://extensions/`，开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择项目中的 `chrome-extension` 目录。
5. 打开已登录的 X 页面，展开长文并向下滚动，让需要的线程和图片进入页面；点击扩展，填写本地地址和配对码，再点“采集当前页面”。
6. 回到“链接商品化”，点击“刷新采集”，从“Chrome 待处理内容”选择刚才的记录。

扩展读取当前页面已加载的长文、同作者线程和最多 8 张原图。页面尚未加载到 DOM 的回复或图片需要先滚动显示。

## 2. 选择交付形式

- **Markdown**：生成 `product.md`，保留标题层级、来源链接、原文快照和随包图片。
- **PDF**：生成内嵌中文字体的 `product.pdf`，适合直接上传网盘或发送给买家。
- **飞书文档**：先生成 Markdown，再通过飞书官方导入任务创建在线文档。
- **Skill**：按文章主题生成独立目录，包含 `SKILL.md`、`agents/openai.yaml`、主题指南、来源核对清单以及专属填写模板。

Skill 会区分 AI 实战、内容运营、学习训练、项目实践和知识整理等主题。工作流、模板字段、检查清单和素材随主题变化，不复用同一套空骨架。

所有本地文件会打进一个 ZIP；生成记录右侧的下载按钮可取回完整包。

## 3. 飞书文档配置

1. 在飞书开放平台创建企业自建应用，并按官方云文档导入接口说明开通云空间、文件上传和文档导入所需权限。
2. 在“链接商品化 → 飞书文档配置”填写 App ID、App Secret。
3. 若要导入指定目录，填写该飞书文件夹 Token；留空时使用应用可写的默认位置。
4. 保存配置并勾选“飞书文档”后生成。成功后，生成记录会显示飞书文档按钮。

App Secret 会加密落库；页面刷新时只显示已配置状态，不回传明文。

## 4. 上传夸克并生成永久交付链接

1. 先在“商品发布 → 夸克网盘 AI 自动上架”保存有效的夸克网页 Cookie。
2. 在“链接商品化”勾选“上传 PDF/ZIP 到夸克并生成永久链接”。
3. 选择上传 PDF 或完整 ZIP；目标目录 FID 留空时沿用夸克自动上架配置中的根目录，也可单独填写。
4. 生成完成后，系统上传产物并以 `expired_type=1` 创建永久分享，保存分享链接、提取码和文件 FID。
5. 生成记录中的云朵按钮可复制完整交付文字。若仍使用本项目自动发货，系统也会同步创建文本卡券和标题匹配规则；改用易店时直接把这段交付文字复制到易店即可。

当前自动上传用于 5MB 以内的 PDF/ZIP，超出时本地 ZIP 仍会正常生成，可自行上传后把永久链接放入易店。

## 5. 推荐操作顺序

1. Chrome 采集 X 长文、线程和图片。
2. 选择来源状态与输出形式，先点击“生成内容包”。
3. 检查并修改商品标题、介绍、售价、类目、封面和详情图。
4. 下载并检查 PDF/Skill，或打开飞书文档核对排版。
5. 上传夸克并复制永久交付信息到易店。
6. 最后在发布表单中上架商品。

内容包会保留来源 URL 和原文快照。涉及外部作者的内容时，先确认实际使用和分发范围，再发布整理稿或 Skill。
